# array_utility

## Overview

`array_utility` provides utilities for streaming numeric arrays.

## Components

| Component | Description |
| --------- | ----------- |
| [types.py](types.py) | Shared NumPy array type aliases (`NumericArray`, `FloatArray`, `IntegerArray`, `UInt8Array`) |
| [ema](ema/README.md) | EMA calculators for numeric and bit-encoded arrays |
| [ring_buffer](ring_buffer/README.md) | Fixed-length ring buffers for numeric and bit-encoded arrays |
| [py.typed](py.typed) | PEP 561 marker for type checkers |

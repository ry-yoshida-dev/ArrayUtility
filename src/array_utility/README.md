# array_utility

## Overview

`array_utility` provides utilities for streaming numeric arrays.

## Components

| Component | Description |
| --------- | ----------- |
| [types.py](types.py) | Shared NumPy array type aliases (`NumericArray`, `FloatArray`, `IntegerArray`, `UInt8Array`) |
| [ema](ema) | EMA calculators and examples |
| [ring_buffer](ring_buffer) | Ring buffer implementations and examples |
